# NexusAI — Project Design

## Problem
Application failures are difficult to detect early.
Engineers need a system that monitors application metrics,
prioritizes incidents, and helps identify possible causes.

## Objectives
1. Collect application metrics and logs.
2. Detect abnormal behavior using machine learning.
3. Prioritize incidents efficiently.
4. Track dependencies between services.
5. Display alerts and analytics in a dashboard.

## Initial Scope
- Java-based incident management engine
- Service and incident models
- Priority queue for incident scheduling
- Command-line demonstration

## Planned Technologies
Java, Spring Boot, PostgreSQL, React, Python,
scikit-learn, Docker and cloud deployment.

## Day 1 Success Criteria
- Project folder created
- Java development environment verified
- Core Java classes implemented
- Incident prioritization demonstrated
- Code committed to Git
